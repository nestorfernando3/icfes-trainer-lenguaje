# Soporte de ICFES Trainer

## Donde pedir ayuda

- **Bugs o errores:** GitHub Issues
- **Sugerencias pedagogicas:** GitHub Issues con contexto del tema o categoria
- **Uso en aula o adaptaciones:** GitHub Issues con el caso de uso

## Incluye esta informacion

- Navegador y dispositivo
- Pasos para reproducir
- Categoria o pregunta afectada
- Captura o mensaje visible, si existe

## Idioma

Se aceptan reportes en espanol o ingles.
