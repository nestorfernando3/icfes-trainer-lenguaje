# Politica de seguridad

Si detectas una vulnerabilidad o un problema sensible, por favor evita publicarlo primero en un issue abierto.

## Como reportar

Envia un correo a `nestorfernando3@hotmail.com` con:

- Descripcion del hallazgo
- Pasos para reproducir
- Impacto esperado
- Version o commit afectado

## Alcance

Nos interesan especialmente reportes relacionados con:

- Exposicion indebida de datos
- Inyeccion de contenido
- Dependencias o configuraciones inseguras

Intentare confirmar la recepcion y responder responsablemente.
