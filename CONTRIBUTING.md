# Contribuir a ICFES Trainer

Gracias por querer mejorar este proyecto educativo.

## Formas de contribuir

- Reportar preguntas con errores o ambiguedades
- Proponer mejoras de UX para estudio en movil o desktop
- Corregir bugs de navegacion, progreso o feedback
- Mejorar documentacion, copy o claridad pedagogica

## Antes de abrir un PR

1. Explica el problema y por que mejora la experiencia del estudiante.
2. Mantén los cambios enfocados y faciles de revisar.
3. Si cambias interfaz o flujo, agrega capturas o una descripcion breve.

## Desarrollo local

```bash
npm install
npm run dev
```

## Prioridades

- Claridad pedagogica
- Accesibilidad
- Rendimiento en navegadores comunes
- Facilidad de uso para estudiantes
